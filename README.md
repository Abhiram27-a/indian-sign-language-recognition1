# Indian Sign Language Recognition

A project for recognizing Indian Sign Language using deep learning.

## Features
- Real-time sign language recognition using a webcam.
- Pretrained CNN model for gesture classification.
- Web-based interface using Flask.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Abhiram27-a/indian-sign-language-recognition1.git

2 Navigate to the project directory:
cd indian-sign-language-recognition1
3 install the required dependencies:
pip install -r requirements.txt

Usage
1 Train the model (if needed):
python src/model_training.py
2 Run the real-time recognition script:
python src/real_time_recognition.py
3 Deploy the web application:
python app/app.py
